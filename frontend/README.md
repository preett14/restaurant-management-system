# Restaurant Management System - Frontend

Frontend for the Restaurant Management System built using React and Vite.

## Features

* User Registration
* User Login
* Menu Display
* Add Menu Item (Admin)
* Order Placement
* Responsive User Interface

## Tech Stack

* React.js
* Vite
* JavaScript
* CSS

## Run Frontend

```bash
npm install
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```
